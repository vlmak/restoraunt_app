#  Restaurant Management System

Информационная система для автоматизации работы ресторана

##  Технологии
* **Язык:** Python 3.14
* **База данных:** PostgreSQL
* **Интерфейс:** PyQt5
* **Работа с БД:** psycopg2

##  Описание проекта
Приложение представляет собой десктопную систему с разграничением прав доступа для 4 ролей:
* **Администратор:** управление залом (бронирование, схемы столиков), просмотр отчетов.
* **Официант:** открытие чеков, добавление блюд.
* **Повар:** кухонный экран, проверка остатков и списание ингредиентов.
* **Менеджер по закупкам:** отслеживание остатков, формирование заказов поставщикам.
